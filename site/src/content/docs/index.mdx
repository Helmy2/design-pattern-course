## Hands-On Branch Catalog

The repository contains 40 dedicated git branches organized as 20 starter and solution pairs:

- **`*-starter` branches:** Contain working but flawed code exhibiting specific design smells (e.g. rigid switches, leaky abstractions, or God objects).
- **`*-solution` branches:** Contain refactored, pattern-driven implementations verified by automated JUnit 5 and ArchUnit tests.

View the complete [Branch Catalog](/design-pattern-course/reference/branches/) to copy checkout commands and inspect test targets.
