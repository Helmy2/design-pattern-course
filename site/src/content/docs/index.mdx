## Curriculum Architecture

This course is structured as four progressive modules preceded by an architectural prologue, moving from foundational engineering trade-offs and code hygiene up to subsystem composition and full architectural boundaries.

## Interactive Learning Tools

Explore the course reference tools designed to accelerate your mastery of Clean Code and GoF Design Patterns:

- **[Pattern Trade-offs: Pros & Cons Guide](/design-pattern-course/reference/pattern-wizard/):** Comprehensive architectural breakdown of all GoF design patterns with tangible pros, drawbacks, over-engineering warnings, and simpler alternatives.
- **[Branch Catalog (40 Branches)](/design-pattern-course/reference/branches/):** Searchable engineering ledger of all 20 starter and solution branch pairs with 1-click `git switch` checkout commands.
- **[Principles Master Index](/design-pattern-course/reference/master-index/):** Searchable architectural matrix connecting SOLID rules, common anti-patterns, and the corresponding GoF patterns that resolve them.
